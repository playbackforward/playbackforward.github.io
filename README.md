# playbackforward.com

Jekyll site, built and served by GitHub Pages from `main`. No build step of our own.

- New article: add `_posts/YYYY-MM-DD-slug.md` with `title` and `description` front matter, then push.
- Drafts: `published: false` in the front matter.
- Colours and fonts follow the brand in the private `studio` repo (`HANDOFF.md`, `engine/brand.json`).
- Domain switch: see `DNS-SETUP.md`.
